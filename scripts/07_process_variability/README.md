## 关键修订说明

本目录经历了两次重要修订，均记录在此：

### 修订一：$$\beta_s$$单位修正(从17.58误读改为56.90 V⁻¹)

早期文档中引用的$$\beta_s = 17.58\,\mathrm{V}^{-1}$$来源于对5 ns批次四参数拟合表格中$$k = 17.576016$$的误读——该值为以mV为单位的**尺度参数**(半宽)，而非以V⁻¹为单位的斜率参数。正确斜率为$$\beta_s = 1/k = 1/(17.576\,\mathrm{mV}) = 56.9\,\mathrm{V}^{-1}$$。

### 修订二：基准从5 ns外部批次改为0.75 ns同批次

用户指出5 ns Sigmoid测量与滞回扫描并非同批次取得，不适合作为NB参数一致性验证的基准。本轮修订改用同批次0.75 ns Psw测量(四条曲线，包含Dev A/B与P→AP/AP→P两方向)作为主基准，5 ns数据降级为外部批次参照。主基准具体参数：

| 量 | 5 ns外部批次(旧) | 0.75 ns同批次主基准(新) |
|:---|:---:|:---:|
| 器件/方向 | 单一单位，P→AP | Device A，AP→P |
| 实测$$\beta_s$$ | 56.9 V⁻¹ | **44.6 V⁻¹** |
| $$V_{\mathrm{th}}$$ | 505 mV | 894 mV |
| C2C经验因子$$\eta_c$$ | 7.05 | **5.6** |
| PDK基线联合预测$$\beta^{\mathrm{eff}}$$ | 56.15 V⁻¹(98.7%实测) | **44.5 V⁻¹(99.7%实测)** |
| 工艺裕度(β保持≥95%) | CV≤15.4% | **CV≤36.5%** |

两次修订均对Néel-Brown反推参数($$\Delta, V_{c0}, \tau_{\mathrm{ret}}, H_k^{\mathrm{eff}}$$)无影响——后者仅依赖于$$V_{\mathrm{th}}(t_w)$$滞回测量，未涉及Sigmoid测量。
