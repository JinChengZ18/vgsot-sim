# Technical Details

This document describes the **physical model**, **device parameters**,
**example simulations**, and **benchmark results** of the VGSOT-MTJ simulator.

The simulator models **voltage-gated spin-orbit torque switching** in magnetic
tunnel junction devices.

## 1. Physics Model

The simulator models magnetization switching of the free layer in a magnetic tunnel junction (MTJ) driven by:

- Spin-Orbit Torque (SOT)
- Voltage-Controlled Magnetic Anisotropy (VCMA)
- Thermal fluctuation field

Magnetization dynamics follow the **Landau–Lifshitz–Gilbert (LLG) equation** with additional torque terms.

### 1.1 Landau–Lifshitz–Gilbert Equation

The magnetization vector $\mathbf{m}$ evolves according to
$$
\frac{d\mathbf{m}}{dt}
=
-\gamma \mathbf{m} \times \mathbf{H}_{eff}
+
\alpha \mathbf{m} \times \frac{d\mathbf{m}}{dt}
+
\tau_{SOT}
+
\tau_{STT}
+
\mathbf{H}_{thermal}
$$
where:

| Symbol                 | Description               |
| ---------------------- | ------------------------- |
| $\gamma$               | gyromagnetic ratio        |
| $\alpha$               | Gilbert damping constant  |
| $\mathbf{H}_{eff}$     | effective magnetic field  |
| $\tau_{SOT}$           | spin-orbit torque         |
| $\tau_{STT}$           | spin-transfer torque      |
| $\mathbf{H}_{thermal}$ | thermal fluctuation field |

### 1.2 Effective Magnetic Field

The effective magnetic field includes several contributions:
$$
\mathbf{H}_{eff}
=
\mathbf{H}_{ani}
+
\mathbf{H}_{demag}
+
\mathbf{H}_{thermal}
$$

#### Anisotropy Field

The perpendicular anisotropy field is given by
$$
H_{ani} =
\frac{2 K_{eff}}{\mu_0 M_s} m_z
$$
where:

| Symbol    | Description                        |
| --------- | ---------------------------------- |
| $K_{eff}$ | effective perpendicular anisotropy |
| $M_s$     | saturation magnetization           |
| $\mu_0$   | vacuum permeability                |

### 1.3 VCMA Effect

Voltage-controlled magnetic anisotropy modifies the anisotropy energy barrier.
$$
K_{eff}(V)
=
K_0 + \xi V
$$
where:

| Parameter | Meaning              |
| --------- | -------------------- |
| $K_0$     | intrinsic anisotropy |
| $\xi$     | VCMA coefficient     |
| $V$       | MTJ voltage          |

Applying voltage across the MTJ temporarily **reduces the energy barrier**, enabling lower-current switching.

### 1.4 Spin-Orbit Torque

The effective field generated by spin-orbit torque is
$$
H_{SOT}
=
\frac{\hbar \theta_{SH} I_{SOT}}
{2 e M_s t_f A}
$$
where:

| Symbol        | Meaning              |
| ------------- | -------------------- |
| $\theta_{SH}$ | spin Hall angle      |
| $t_f$         | free layer thickness |
| $A$           | device area          |
| $I_{SOT}$     | SOT current          |

This torque drives deterministic magnetization switching.

### 1.5 Thermal Noise

Thermal fluctuations are modeled as a stochastic magnetic field, sampled per timestep:
$$
\mathbf{H}_{thermal}
=
\boldsymbol{\xi}\sqrt{
\frac{2 \alpha k_B T}
{\gamma \mu_0 M_s V \Delta t}
}
,\qquad
\xi_i \sim \mathcal{N}(0,1)\ \text{i.i.d.}
$$
where:

| Symbol     | Meaning                  |
| ---------- | ------------------------ |
| $k_B$      | Boltzmann constant       |
| $T$        | temperature              |
| $\Delta t$ | simulation timestep      |
| $\xi_i$    | independent standard Gaussian |

Each Cartesian component of $\mathbf{H}_{thermal}$ is an independent standard Gaussian (fluctuation–dissipation theorem, Brown 1963). In particular, $|\mathbf{H}_{thermal}|^2$ follows a chi-square distribution with three degrees of freedom and **must not be normalised to unit length** — doing so (as the upstream Python port did) cuts the injected noise power by roughly a factor of three and produces visibly too-sharp $P_{sw}(V)$ curves near threshold. `stochastic.py` in this release returns three i.i.d. $\mathcal{N}(0,1)$ samples; the scaling is applied by `anisotropy.field()`.

Thermal noise is responsible for **switching stochasticity** and **error rate**.

## 2. Device Parameters

The simulator uses a set of physical constants and device parameters defined in the implementation (see `constants.py`). constants

These parameters describe the MTJ geometry, magnetic properties, transport properties, and simulation settings.

### 2.1 Fundamental Physical Constants

Stored in `PhysicalConstantsConfig` (`configs.py`). Values are limited-precision approximations; for higher fidelity use CODATA recommendations.

| Parameter               | Symbol  | Value                 | Unit | Description          |
| ----------------------- | ------- | --------------------- | ---- | -------------------- |
| Vacuum permeability     | $\mu_0$ | $1.25663706\times10^{-6}$ | H/m  | Magnetic constant    |
| Elementary charge       | $e$     | $1.6\times10^{-19}$   | C    | Charge of electron   |
| Reduced Planck constant | $\hbar$ | $1.054\times10^{-34}$ | J·s  | Quantum constant     |
| Bohr magneton           | $\mu_B$ | $9.274\times10^{-24}$ | J/T  | Magnetic moment unit |
| Boltzmann constant      | $k_B$   | $1.38\times10^{-23}$  | J/K  | Thermal energy scale |
| Electron mass           | $m_e$   | $9.11\times10^{-31}$  | kg   | Electron mass        |

Derived quantity used in the LLG equation:
$$
\gamma = \frac{2\mu_0 \mu_B}{\hbar}
$$
where $\gamma$ is the gyromagnetic ratio.

### 2.2 Device Geometry

The simulated device is a 80 nm circular MTJ on top of a β-W heavy-metal channel, matching the 300 mm wafer platform of Section 2.3.1 of the thesis.

| Parameter             | Symbol   | Value | Unit | Description              |
| --------------------- | -------- | ----- | ---- | ------------------------ |
| Heavy metal length    | $l$      | 240   | nm   | SOT channel length       |
| Heavy metal width     | $w$      | 200   | nm   | SOT channel width        |
| Heavy metal thickness | $d$      | 4.3   | nm   | SOT channel thickness    |
| MTJ diameter          | $D$      | 80    | nm   | Free-layer physical diameter |
| Free layer thickness  | $t_f$    | 1.1   | nm   | Magnetic layer thickness |
| Barrier thickness     | $t_{ox}$ | 1.4   | nm   | Tunnel barrier thickness |

> **Note on electrical vs physical diameter.** The thesis (Section 2.2.2.4 / 2.3.1) distinguishes the physical diameter $D_{phys}$ from the electrical effective diameter $D_{elec} \approx D_{phys} - 2\delta_{edge} \approx 65$ nm; the latter is what reconciles the wafer-measured $R_P=10.89\ \text{k}\Omega$ with $RA = 36\ \Omega\cdot\mu\text{m}^2$. The current `configs.py` separates the two — `D` = $D_{phys}$ = 80 nm and `D_elec` ≈ 65 nm — and builds the MTJ area $A_1$ from $D_{elec}$.

Derived areas and volumes:

Cross-sectional area of the SOT channel
$$
A_2 = w \cdot d
$$
MTJ area
$$
A_1 = \frac{\pi D^2}{4}
$$
Free-layer volume
$$
V = t_f A_1
$$

### 2.3 Magnetic Material Parameters

| Parameter                | Symbol        | Value               | Unit | Description                        |
| ------------------------ | ------------- | ------------------- | ---- | ---------------------------------- |
| Interfacial anisotropy   | $K_i$         | $0.32\times10^{-3}$ | J/m² | Perpendicular anisotropy           |
| Saturation magnetization | $M_s$         | $6.25\times10^5$    | A/m  | Free-layer magnetization           |
| Gilbert damping          | $\alpha$      | 0.05                | –    | Damping constant                   |
| Spin Hall angle          | $\theta_{SH}$ | **0.066** (calibrated; 0.04 pre-fix, 0.25 textbook) | –    | Effective SOT efficiency — see note below |
| Spin polarization        | $P$           | 0.58                | –    | Tunnel current spin polarization   |
| Temperature              | $T$           | 300                 | K    | Operating temperature              |

> **Note on calibrated $\theta_{SH}$.** The literature β-W value $\theta_{SH}\!\approx\!0.25$ leaves the simulator's deterministic threshold at $|I_{SOT}|\!\approx\!140\,\mu\mathrm{A}$ ($V_{SOT}\!\approx\!109\,\mathrm{mV}$ for $R_W\!\approx\!776\,\Omega$), about $8\times$ lower than the same-batch Device A P→AP detailed-$P_{sw}$ value $V_{th}(0.75\,\mathrm{ns})\!\approx\!894\,\mathrm{mV}$ ($I_{th}\!\approx\!1152\,\mu\mathrm{A}$) extracted in Section 2.3.3 (Sigmoid fit, $\beta_s = 44.6\,\mathrm{V^{-1}}$). A scan over $\theta_{SH}$ combinations (see `09_simulation_figures/calibrate_to_experiment.py`) converges on $\theta_{SH}\!\approx\!0.066$ as the calibration that — jointly with $TMR = 1.0$ and $RA = 16.6\times 10^{-12}\,\Omega\cdot\mathrm{m}^2$ — reproduces the same-batch $V_{th}(0.75\,\mathrm{ns})$ within $\sim 1\%$. This is the calibrated value used as the package default. The deviation from the textbook β-W value absorbs additional loss channels not in this simplified model: Néel–Edelstein contributions, interfacial spin-memory loss, top-electrode parasitic series resistance, and (over the pulse window) any partial misalignment between charge-current and the assumed σ̂ axis. For material-level studies of the bare spin Hall effect, override with `theta_SH=0.25` (or any literature value).

Effective anisotropy field:
$$
H_{eff} =
\frac{2K_i}{t_f M_s \mu_0}
$$
This determines the intrinsic stability of the perpendicular magnetization.

### 2.4 VCMA Parameters

Voltage-controlled magnetic anisotropy modifies the effective anisotropy.

| Parameter        | Symbol  | Value              | Unit    | Description     |
| ---------------- | ------- | ------------------ | ------- | --------------- |
| VCMA coefficient | $\beta$ | $60\times10^{-15}$ | J/(V·m) | VCMA efficiency |

The anisotropy energy changes with voltage:
$$
K_{eff}(V) = K_0 + \beta V
$$
This effect lowers the switching energy barrier during the voltage pulse.

### 2.5 Electronic Transport Parameters

| Parameter                | Symbol       | Value              | Unit | Description              |
| ------------------------ | ------------ | ------------------ | ---- | ------------------------ |
| Heavy metal resistivity  | $\rho$       | $278\times10^{-8}$ | Ω·m  | β-W channel resistivity  |
| Channel resistance       | $R_W$        | computed (≈ 776 Ω) | Ω    | SOT channel resistance   |
| Resistance-area product  | $RA$         | $36\times10^{-12}$ | Ω·m² | MTJ resistance area      |
| TMR ratio                | TMR          | 1.19               | –    | Zero-bias tunnel magnetoresistance |
| Bias suppression voltage | $V_h$        | 0.5                | V    | Lorentzian TMR(V) half-decay |
| Barrier height           | $\phi_{bar}$ | 0.4                | eV   | Tunnel barrier height    |

Channel resistance is computed as
$$
R_W = \frac{\rho l}{wd}
$$
The MTJ resistance depends on the magnetization orientation through the TMR relation.

#### Bias-dependent TMR(V) selector

Two models are available, selected via `constants.tmr_model`:

- `"lorentzian"`: $\mathrm{TMR}(V) = \mathrm{TMR}_0 / (1 + (V/V_h)^2)$
- `"pdk"` (default): three-parameter Hikstor PDK form
  $$
  \mathrm{TMR}_{\mathrm{PDK}}(V) = \frac{\mathrm{TMR}_0}{k_{\mathrm{TMR}}}\left[\frac{1}{a_{\mathrm{TMR}} V^2 + b_{\mathrm{TMR}} |V| + c_{\mathrm{TMR}}} - 1\right]
  $$

PDK coefficient defaults (from thesis Table 2.2.2.5):

| Parameter | Default  | Unit  |
| --------- | -------- | ----- |
| $k_{\mathrm{TMR}}$ | 1.2346  | –   |
| $a_{\mathrm{TMR}}$ | 0.1729  | 1/V² |
| $b_{\mathrm{TMR}}$ | 0.1315  | 1/V  |
| $c_{\mathrm{TMR}}$ | 0.4475  | –   |

The full resistance is computed by conductance interpolation:
$$
R(m_z, V) = R_P \cdot \frac{1 + \mathrm{TMR}_{\mathrm{eff}}(V)}{1 + \mathrm{TMR}_{\mathrm{eff}}(V)\cdot(1+m_z)/2}
$$
with the code convention $m_z = +1 \to R_P$, $m_z = -1 \to R_{AP}(V) = R_P(1+\mathrm{TMR}_{\mathrm{eff}}(V))$.

#### In-plane bias field $\mathbf{H}_{ex}$

The bias field used to deterministically break SOT switching chirality (thesis Section 2.3.3) is exposed as three scalar fields in `PhysicalConstantsConfig`. **Sign / direction convention is critical** — see configs.py for the in-line note.

| Parameter | Default                | Unit | Description              |
| --------- | ---------------------- | ---- | ------------------------ |
| `h_ex_x`  | 0                      | A/m  |                          |
| `h_ex_y`  | $-50 \times 10^3 / (4\pi) \approx -3979$ | A/m | $-50$ Oe perpendicular to σ_SH |
| `h_ex_z`  | 0                      | A/m  |                          |

The closed-form LLG in `dynamic_switching.py` is expanded with the implicit
σ_SH = $-\hat{x}$. **`H_ex` MUST be perpendicular to σ_SH** for SOT to be
deterministic: with $\mathbf{H}_{ex} \parallel \hat\sigma$ the in-plane
equilibrium under SOT is symmetric about the easy axis, the final $m_z$
basin is selected with $\sim 50\%$ probability, and the SER curve flattens
to a $\sim 0.5$ random-bit plateau (we verified this by direct $2\times2$
factorial experiment, see thesis §2.2.6 engineering note). The chapter's
"$200\,\mathrm{Oe}$ along current direction" maps to the simulator's
`h_ex_y` (with the sign that gives the desired switching chirality)
because the code's implicit current direction is along $\hat{y}$.

The 50-Oe magnitude (vs the experimental 200 Oe) is a simulator-tuned
value. Smaller $|\mathbf{H}_{ex}|$ keeps the in-plane equilibrium close
to σ_SH, which the simplified SOT/FL torque expansion handles cleanly;
the full experimental 200 Oe gives correct chirality but exhibits a
higher residual SER tail (~0.4) due to mechanisms (Néel-type DMI,
interface roughness, FL components) not yet in this model.

### 2.6 Spin-Orbit Torque Parameters

Spin-orbit torque strength depends on material and geometry:

| Parameter            | Symbol        | Value    | Unit | Description                                          |
| -------------------- | ------------- | -------- | ---- | ---------------------------------------------------- |
| Spin Hall angle      | $\theta_{SH}$ | 0.066    | –    | Effective SOT efficiency (calibrated; see §2.3 note) |
| SOT current          | $I_{SOT}$     | variable | A    | Applied current                                      |
| Free-layer thickness | $t_f$         | 1.1      | nm   | Magnetic thickness                                   |

Effective SOT field:
$$
H_{SOT}
=
\frac{\hbar \theta_{SH} I_{SOT}}

$$
This field produces the torque responsible for magnetization switching.

## 4. Benchmark Results

> **Calibrated baseline.** All numbers below use the package defaults
> ($\theta_{SH} = 0.066$, $TMR = 1.0$, $RA = 16.6\times 10^{-12}\,\Omega\cdot\mathrm{m}^2$,
> $D_{elec} = 65\,\mathrm{nm}$). With the literature $\theta_{SH} = 0.25$ all
> threshold currents drop by roughly the $0.25/0.066 \approx 3.8$ ratio.

### 4.1 Switching Current Threshold

Switching occurs when
$$
|I_{SOT}| > I_{critical}
$$
With the calibrated defaults at $t_w = 0.75\,\mathrm{ns}$ (chapter §2.3.3
detailed-$P_{sw}$ protocol, Device A P→AP target):
$$
I_{critical}(0.75\,\mathrm{ns}) \approx 1.1\text{–}1.2\,\mathrm{mA}
\quad (V_{th} \approx 894\,\mathrm{mV})
$$
This matches the same-batch experimental Sigmoid fit
($V_{th} = 894\,\mathrm{mV}$, $\beta_s = 44.6\,\mathrm{V^{-1}}$) within $\sim 1\%$.

### 4.2 VCMA-Assisted Switching

Voltage assistance reduces the required switching current. With VCMA enabled
and $V_{MTJ}$ pulses chosen to lower the barrier during the SOT pulse, the
required $|I_{SOT}|$ drops below the no-VCMA threshold. The dedicated CLI
cases for this regime (`vcma_assisted_switching_*`, `optimized_vgsot_switching`,
`ser_optimized_vgsot`) were removed in 2026-05 since they had no counterpart
in the same-batch Device A measurements. To explore VCMA-assisted protocols
today, drive `run_piecewise_direct_excitation` from a Python loop with a
non-zero `v_mtj_stage*` and `vnv=1`.

### 4.3 Switching Error Rate (SER)

Monte-Carlo simulations evaluate switching reliability. The chapter §2.3.3
$P_{sw}(V)$ Sigmoid corresponds to the SER curve produced by
`ser_sot_no_vcma_thermal(..., enable_self_heating=True)` swept across the
calibrated threshold zone; with the package defaults the 50% midpoint sits
near $|I_{SOT}| \approx 1.15\,\mathrm{mA}$ and the slope-equivalent
$\beta_s \approx 44\text{–}45\,\mathrm{V^{-1}}$, consistent with experiment.
Higher current reduces stochastic switching failures.

## 2.7 Reproducibility — end-to-end `rng=…`

`stochastic()`, `init()`, `field()`, `switching()`, and `run_piecewise_*` all accept an optional `rng=np.random.Generator`. Passing the same generator state reproduces a Monte-Carlo trial bit-for-bit, regardless of any other code path that may also be consuming `np.random.*`:

```python
import numpy as np
from vgsot_sim.time_series_cases import run_piecewise_direct_excitation

rng = np.random.default_rng(seed=42)
res = run_piecewise_direct_excitation(..., rng=rng)
```

When `rng=None` (default) the legacy global `np.random` state is used, so `np.random.seed(42)` still works for older scripts.

### 2.7.1 Per-trial RNG mode in `ser_sot_no_vcma_thermal`

The Monte-Carlo SER case adds two complementary toggles:

```python
ser_sot_no_vcma_thermal(
    cfg,
    seed=2026,
    rng_mode="legacy",       # "legacy" | "generator"
    integrator=None,         # None | "euler_spherical" | "cayley"
)
```

| `rng_mode`   | Source of trial randomness                       | When to use |
|--------------|--------------------------------------------------|-------------|
| `"legacy"`   | `np.random.seed(trial_seed)` (default)           | Reproduce chapter figures byte-for-byte |
| `"generator"`| `np.random.default_rng(trial_seed)` per trial    | Multiprocessing, embedding inside larger MC drivers; cleaner — does not touch global numpy state |

Both modes derive `trial_seed` from the same `_trial_seed(seed, i_sot, idx)` helper, so the *sequence of seeds* is identical; only the underlying generator differs. Statistical results converge in N → ∞ but the bit-streams of the two modes are distinct.

The `integrator` argument is forwarded straight to `run_piecewise_direct_excitation`, so an MC sweep can be re-run on Cayley by passing `integrator="cayley"` without touching the global default.

### 2.7.2 Symmetric coverage on `run_piecewise_terminal_voltage`

Both piecewise drivers now accept the same opt-in trio (`integrator=`, `sigma_SH=`, `rng=`), so terminal-voltage simulations (with the three-terminal $V_1 / V_2 / V_3$ excitation pattern) can opt into Cayley + arbitrary σ̂_SH + byte-reproducible noise just like the direct-current driver. Their defaults are `("cayley", None, None)`; passing `integrator="euler_spherical"` reproduces the legacy spherical-stepper behaviour.

```python
from vgsot_sim.time_series_cases import run_piecewise_terminal_voltage
from vgsot_sim.configs import TerminalVoltageControlConfig

rng = np.random.default_rng(seed=2026)
cfg = TerminalVoltageControlConfig(...)
res = run_piecewise_terminal_voltage(
    cfg,
    integrator="cayley",
    sigma_SH=np.array([0.0, -1.0, 0.0]),   # rotate σ̂_SH off the default -x
    rng=rng,
)
```

The Cayley path in turn forwards `rng=` all the way down to `stochastic()` via `switching_vector → field → stochastic`, so the thermal-noise stream is byte-reproducible end-to-end. Verified by `tests/test_toggles.py::test_cayley_rng_byte_reproducible`.

## 4.5 Integrators

Two LLG steppers are available; choose via `run_piecewise_direct_excitation(..., integrator=)`:

| Integrator         | Coordinates    | Norm preservation | Cost / step | σ̂_SH parameter | Module |
|--------------------|----------------|-------------------|-------------|-----------------|--------|
| `"euler_spherical"` | $(\theta, \phi)$ | analytic (1) | low | implicit $-\hat{x}$ | `dynamic_switching.py` |
| `"cayley"` (default) | $(m_x, m_y, m_z)$ | machine-precision (2) | ~2× | runtime arg | `dynamic_switching_vector.py` |

(1) Spherical exact arithmetic preserves $|\mathbf{m}|=1$ analytically but the $1/\sin\theta$ term in $d\phi/dt$ amplifies round-off near the poles (a polar-region guard exists in code).

(2) The Cayley transform $\mathbf{m}_{n+1} = (I-\tfrac{\Delta t}{2}[\omega]_\times)^{-1}(I+\tfrac{\Delta t}{2}[\omega]_\times)\mathbf{m}_n$ is an exact rotation; the implementation uses the closed-form
$$\mathbf{m}_{n+1} = \mathbf{m}_n + \frac{2s}{1 + s^2|\omega|^2}\bigl(\omega\times\mathbf{m}_n + s\,\omega\times(\omega\times\mathbf{m}_n)\bigr),\ s=\Delta t/2.$$
The Cayley step accepts `sigma_SH` and `sigma_STT` as runtime 3-vectors, removing the σ̂ direction ambiguity of the legacy spherical expansion. Since the FL-SOT $\cos\theta\cos\phi$ sign correction (2026-06) the two steppers reduce to the SAME right-hand side — verified to $<10^{-4}$ in $d\mathbf{m}/dt$ as $\Delta t \to 0$ by `tests/test_integrator_consistency.py`. Any residual difference in switching outcome near the threshold transition zone therefore comes from the integration scheme itself (explicit spherical Euler with a $1/\sin\theta$ polar guard versus the norm-preserving Cayley rotation), not from a torque-sign discrepancy.

For new work that needs an explicit σ̂_SH (e.g. material studies with non-standard heavy-metal stacks) or that runs near the polar singularity, prefer `integrator="cayley"`. For regression against the §2.3 chapter figures keep the spherical default.

## 5. Full LLG Derivation

This section gives a compact derivation of the magnetization dynamics used in the simulator.

### 5.1 Precessional Dynamics

Let the unit magnetization vector be
$$
\mathbf{m} = \frac{\mathbf{M}}{M_s}, \qquad |\mathbf{m}| = 1
$$
Under an effective magnetic field $\mathbf{H}_{eff}$, the torque on the magnetic moment is
$$
\mathbf{T} = -\gamma \mathbf{M} \times \mathbf{H}_{eff}
$$
Dividing by $M_s$ gives the precessional dynamics of the normalized magnetization:
$$
\frac{d\mathbf{m}}{dt}
=
-\gamma \mathbf{m} \times \mathbf{H}_{eff}
$$
This term causes precession of $\mathbf{m}$ around the effective field.

### 5.2 Gilbert Damping

Pure precession does not relax the magnetization toward equilibrium, so the Gilbert damping term is added:
$$
\frac{d\mathbf{m}}{dt}
=
-\gamma \mathbf{m} \times \mathbf{H}_{eff}
+
\alpha \mathbf{m} \times \frac{d\mathbf{m}}{dt}
$$
where $\alpha$ is the Gilbert damping constant.

To obtain an explicit equation, move the damping-related term to the left-hand side and solve for $d\mathbf{m}/dt$. The explicit Landau–Lifshitz–Gilbert form is
$$
\frac{d\mathbf{m}}{dt}
=
-\frac{\gamma}{1+\alpha^2}\,\mathbf{m}\times\mathbf{H}_{eff}
-
\frac{\alpha\gamma}{1+\alpha^2}\,\mathbf{m}\times\left(\mathbf{m}\times\mathbf{H}_{eff}\right)
$$
The first term is the precession term, and the second term drives energy dissipation.

### 5.3 Inclusion of Spin-Orbit Torque

For a spin polarization direction $\boldsymbol{\sigma}$, the damping-like and field-like SOT contributions can be written as
$$
\boldsymbol{\tau}_{DL}
=
-\gamma H_{DL}\,\mathbf{m}\times(\mathbf{m}\times\boldsymbol{\sigma})
$$
Thus the full dynamics become
$$
\frac{d\mathbf{m}}{dt}
=
-\frac{\gamma}{1+\alpha^2}\,\mathbf{m}\times\mathbf{H}_{eff}
-
\frac{\alpha\gamma}{1+\alpha^2}\,\mathbf{m}\times\left(\mathbf{m}\times\mathbf{H}_{eff}\right)
+
\boldsymbol{\tau}_{DL}
+
\boldsymbol{\tau}_{FL}
+
\boldsymbol{\tau}_{STT}
$$
In many VGSOT operating regimes, the dominant current-driven term is the damping-like SOT.

### 5.4 Effective Field Expansion

The effective field is written as
$$
\mathbf{H}_{eff}
=
\mathbf{H}_{ani}
+
\mathbf{H}_{demag}
+
\mathbf{H}_{ex}
+
\mathbf{H}_{thermal}
+
\mathbf{H}_{VCMA}
$$
where:

- $\mathbf{H}_{ani}$ is the perpendicular anisotropy field
- $\mathbf{H}_{demag}$ is the demagnetization field
- $\mathbf{H}_{ex}$ is the exchange or bias-like contribution
- $\mathbf{H}_{thermal}$ is the stochastic thermal field
- $\mathbf{H}_{VCMA}$ is the voltage-induced anisotropy modulation

For perpendicular anisotropy,
$$
H_{ani}
=
\frac{2K_{eff}}{\mu_0 M_s} m_z
$$
and with VCMA,
$$
K_{eff}(V)
=
K_0 + \xi V
$$
Therefore, the voltage dependence enters the LLG equation through $\mathbf{H}_{eff}$.

### 5.5 Spherical Coordinate Interpretation

If the magnetization is parameterized by polar angle $\theta$ and azimuthal angle $\phi$,
$$
m_x = \sin\theta\cos\phi,\qquad
m_y = \sin\theta\sin\phi,\qquad
m_z = \cos\theta
$$
then switching corresponds to a transition between two stable out-of-plane states:
$$
m_z \approx +1
\quad \longrightarrow \quad
m_z \approx -1
$$
or vice versa.

In this representation:

- $\theta$ describes the deviation from the perpendicular axis
- $\phi$ describes in-plane precession
- switching occurs when the trajectory crosses the energy barrier and relaxes into the opposite basin

### 5.6 Energy Picture

The magnetic free-energy density can be written schematically as
$$
E(\theta)
=
K_{eff}\sin^2\theta
+
E_{demag}
+
E_{bias}
$$
For perpendicular devices, the two stable states correspond to the two minima near
$$
\theta \approx 0
\quad \text{and} \quad
\theta \approx \pi
$$
VCMA reduces $K_{eff}$, thereby lowering the barrier between the two minima. SOT then drives the magnetization across the reduced barrier.

## 6. Switching Phase Diagram

A switching phase diagram is a compact way to visualize which combinations of control parameters lead to successful reversal.

### 6.1 General Definition

Let the final switched state be defined by
$$
m_z(t_{final}) < m_{th}
$$
for a chosen threshold $m_{th}$, for example
$$
m_{th} = -0.9
$$
Then the switching phase diagram over two control parameters $p_1$ and $p_2$ is
$$
\mathcal{S}(p_1, p_2)
=
\begin{cases}
1, & \text{successful switching} \\
0, & \text{switching failure}
\end{cases}
$$
Typical choices are:

- $p_1 = I_{SOT}$, $p_2 = V_{MTJ}$
- $p_1 = I_{SOT}$, $p_2 = t_{pulse}$
- $p_1 = t_1$, $p_2 = t_2$ for the two-pulse scheme

### 6.2 Common Regimes

A typical $I_{SOT}$–$V_{MTJ}$ phase diagram contains three regions:

| Region                  | Description                      | Physical Meaning                            |
| ----------------------- | -------------------------------- | ------------------------------------------- |
| No switching            | current and/or voltage too small | barrier remains too high or torque too weak |
| Probabilistic switching | near threshold                   | thermal noise strongly affects outcome      |
| Deterministic switching | sufficient VCMA + sufficient SOT | robust reversal                             |

This can be summarized qualitatively as
$$
\text{Switching boundary:} \qquad I_{SOT}^{crit} = f(V_{MTJ})
$$
with
$$
\frac{d I_{SOT}^{crit}}{d V_{MTJ}} < 0
$$
meaning that stronger voltage assistance lowers the required switching current.

### 6.3 Two-Pulse Phase Diagram

For the optimized two-pulse VGSOT scheme, one often studies a phase diagram in the $t_1$–$t_2$ plane:
$$
\mathcal{S}(t_1, t_2)
$$
Interpretation:

- small $t_1$: barrier-lowering pulse too short
- small $t_2$: switching pulse too short
- excessively large total pulse length: unnecessary energy cost
- an intermediate region gives robust switching with improved efficiency

A useful practical constraint is
$$
t_1 + t_2 = t_{total}
$$
so that the design problem reduces to finding the best pulse partition.

### 6.4 Recommended Plot for This Repository

For this simulator, the most informative phase diagrams are:

| X-axis    | Y-axis                            | Meaning                              |
| --------- | --------------------------------- | ------------------------------------ |
| $I_{SOT}$ | $V_{MTJ}$                         | VCMA-assisted switching threshold    |
| $t_1$     | $t_2$                             | optimized two-pulse switching region |
| $I_{SOT}$ | thermal noise level / temperature | robustness map                       |

Each point can be colored by:

- final state $m_z(t_{final})$
- switching probability
- switching delay
- SER

## 7. SER Scaling Law

Switching Error Rate (SER) quantifies the probability that the device fails to reach the desired state under stochastic fluctuations.

### 7.1 Definition

For $N$ Monte-Carlo trials and $N_f$ failures,
$$
SER = \frac{N_f}{N}
$$
A failure is typically defined as
$$
|m_z(t_{final}) - m_{target}| > \varepsilon
$$
where:

| Symbol        | Meaning             |
| ------------- | ------------------- |
| $m_{target}$  | desired final state |
| $\varepsilon$ | tolerance threshold |

### 7.2 Qualitative Scaling with Current

In thermally activated switching, the error rate typically decreases rapidly as the drive current exceeds threshold. A commonly used qualitative form is
$$
SER(I_{SOT})
\sim
\exp\left(
-\frac{\Delta E_{eff}(I_{SOT})}{k_B T}
\right)
$$
where $\Delta E_{eff}$ is the effective barrier under applied drive.

As $I_{SOT}$ increases, the effective barrier is reduced for the undesired trajectory and the correct switching path becomes more favorable, so SER decreases approximately exponentially.

A simple linearized barrier model is
$$
\Delta E_{eff}(I_{SOT})
=
\Delta E_0
\left(1 - \frac{|I_{SOT}|}{I_c}\right)^\eta
$$
for some critical current $I_c$ and exponent $\eta$.

This yields
$$
SER(I_{SOT})
\sim
\exp\left[
-\frac{\Delta E_0}{k_B T}
\left(1 - \frac{|I_{SOT}|}{I_c}\right)^\eta
\right]
$$
for near-threshold operation.

### 7.3 Scaling with Voltage Assistance

VCMA reduces the anisotropy barrier, which changes the effective switching landscape. A simple phenomenological form is
$$
\Delta E_{eff}(V_{MTJ})
=
\Delta E_0 - \lambda V_{MTJ}
$$
Thus
$$
SER(V_{MTJ})
\sim
\exp\left(
-\frac{\Delta E_0 - \lambda V_{MTJ}}{k_B T}
\right)
$$
In practice, VCMA can reduce the required current for a target SER.

### 7.4 Scaling with Pulse Width

For pulse-driven switching, the error rate also depends strongly on pulse duration. A common empirical trend is
$$
SER(t_p)
\sim
\exp\left(-\frac{t_p}{\tau_{sw}}\right)
$$
where $\tau_{sw}$ is an effective switching timescale.

Longer pulses generally reduce SER, but with diminishing returns and increased energy cost.

For the two-pulse scheme,
$$
SER = SER(t_1, t_2)
$$
and an optimal operating region exists where:

- $t_1$ is long enough to lower the barrier
- $t_2$ is long enough to complete reversal
- total pulse energy remains acceptable

### 7.5 Log-Scale Interpretation

Because SER often spans many orders of magnitude, it is usually analyzed on a logarithmic scale:
$$
\log_{10}(SER)
$$
This is especially useful when comparing:

- current scaling
- temperature scaling
- pulse-width scaling
- VCMA-assisted vs non-assisted switching
